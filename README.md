# 🛒 E-Store - Modern E-Commerce Platform

A fast, responsive, and secure **E-Commerce Web Application** built using **React (Vite)**, **TypeScript**, and **Tailwind CSS**. It features robust user authentication and management powered by **Clerk**.

## 🚀 Live Demo

👉 [View Live Demo](https://your-live-demo-link.com)

---

## ✨ Features

- **Secure Authentication:** Seamless login, registration, and profile management using **Clerk**.
- **Product Catalog:** Dynamic product browsing with category filtering and sorting.
- **Detailed Product Views:** Dedicated pages for single items with full specifications.
- **Type Safety:** 100% written in **TypeScript** to ensure bug-free data flow and great developer experience.
- **Modern UI/UX:** Clean, modern, and fully responsive design built with **Tailwind CSS**.
- **Fast Build Times:** Powered by **Vite** for near-instant server starts and Hot Module Replacement (HMR).

---

## 🛠️ Tech Stack

- **Frontend Framework:** React 18+ (Vite)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Authentication:** Clerk Auth
- **Routing:** React Router DOM
